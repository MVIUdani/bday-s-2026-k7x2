# Birthday Surprise Website 🎂❤️

A simple customizable birthday website made with HTML, CSS and JavaScript.

## How to open

1. Keep `index.html`, `style.css`, `script.js` in the same folder.
2. Double-click `index.html`.
3. It will open in your browser.

## Customize first

Open `index.html` and replace:

- `YOUR_NAME_HERE`
- `YOUR_AGE_HERE`
- `YOUR_CAPTION_1`
- `YOUR_CAPTION_2`
- `YOUR_CAPTION_3`
- `YOUR_BIRTHDAY_MESSAGE_HERE`

Then open `script.js` and edit the birthday gift messages.

## Add photos

Put your photos in the `images` folder.

You can later change the photo placeholder `<div>` in `index.html` to:

<img src="images/photo1.jpg" alt="Our memory">

## Birthday date

The countdown is configured for October 12 in `script.js`.

## Hosting

After customizing, you can upload this project to GitHub and enable GitHub Pages to get a shareable link.
